TUFReplay-Renderer의 첫 공개 베타입니다. 별도 OrbitRender 모드 없이 기록된 플레이를 영상으로 렌더링합니다.

- 웹의 실행 기록 ⋯ 메뉴에서 렌더 설정, 진행 상태, 취소와 완료 후 저장 위치 열기를 제공합니다.
- 게임의 키뷰어·오버레이, ImplDmNote 손/발 키뷰어와 녹화된 카메라·마이크를 영상에 합성합니다.
- 중간 타일에서 시작한 기록과 실패 애니메이션을 지원하고, 클리어·실패 후 대기 시간을 설정할 수 있습니다.
- FFmpeg는 최신 TUFReplay의 웹 설치 동의를 거쳐 `Mods/TUFReplay/FFmpeg`에 설치하며 두 모드가 함께 사용합니다.
- TUFReplay 다운로드 센터가 이 릴리스의 ZIP과 검증 manifest를 받아 자동으로 설치할 수 있습니다. 설치 후 ADOFAI를 완전히 다시 시작해 주세요.

최신 다운로드 센터를 포함한 TUFReplay와 AdofaiIpc 0.4.1 이상이 필요합니다. ImplDmNote 오버레이를 사용하려면 렌더 IPC를 지원하는 ImplDmNote 버전을 실행해 주세요. 별도 OrbitRender 모드는 중복 패치를 피하도록 꺼 주세요.

Windows 실제 게임·카메라 테스트는 진행 전입니다. 베타 테스트 중 문제를 발견하면 웹 오류 상세와 게임 로그를 함께 확인해 주세요.

TUFReplay-Renderer는 GPL 라이선스를 따르는 별도 프로젝트입니다. FFmpeg 실행 파일과 게임 어셈블리는 이 ZIP에 포함하지 않습니다.
