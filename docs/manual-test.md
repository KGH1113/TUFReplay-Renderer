# 실게임 확인

자동 빌드·데이터 계약·FFmpeg 합성·ImplDmNote 네이티브 화면 검증과 실제 게임 검증을 구분합니다. 개발 과정에서는 게임을 실행하거나 설치 폴더를 변경하지 않았습니다.

0번 타일부터 시작한 전체 플레이와 중간 타일·체크포인트에서 시작한 기록을 지원합니다. 실패한 기록은 사망 애니메이션과 폭발을 표시한 뒤 설정한 시간만큼 더 렌더링합니다. 필요한 타이밍·판정 정보가 없는 예전 기록은 새로 녹화해야 합니다.

설치 파일은 `~/dev/src/tuf-replay-render/build/TUFReplay.zip`, `~/dev/src/TUFReplay-Renderer/Release/TUFReplay-Renderer.zip`에 있습니다. ImplDmNote는 `~/dev/src/impl-resourcepack-render/apps/impl-dm-note`에서 빌드한 앱을 사용합니다. 설치 폴더를 바꾸기 전 게임과 기존 ImplDmNote를 종료합니다. 새 웹 화면은 다음 명령으로 실행합니다.

```sh
cd ~/dev/src/tuf-replay-render
./scripts/run.sh web-dev
```

1. 새 TUFReplay와 TUFReplay-Renderer를 설치하고 AdofaiIpc 0.4.1 이상을 활성화합니다. 별도 OrbitRender는 비활성화합니다. 웹도 `codex/replay-rendering` 작업 폴더의 빌드로 실행합니다. 게임 안에 예전 Orbit 설정창·F6 메뉴·완료창이 나타나지 않아야 합니다.
2. 원래 레벨과 필요한 게임 모드가 설치된 최근 클리어 기록에서 **⋯ → Render → 1080p60**을 실행합니다. 저장 폴더를 선택하고 판정 수, 마지막 타일, 클리어 시점과 영상 길이를 일반 리플레이와 비교합니다. 진행 UI와 미리보기는 화면에 보이되 결과 영상에는 들어가지 않아야 합니다.
3. 카메라의 위치·크롭·좌우 반전·보정 시간을 확인합니다. 마이크의 시작 시점·음량을 확인하고 게임 오디오가 함께 남아 있는지 듣습니다. 배속 기록도 한 번 확인합니다.
4. 키뷰어에서 카운트다운 입력, 짧은 입력, 동시 입력, 홀드, 횟수와 레인 효과를 확인합니다. 음수 시간만으로 타이밍·판정 누락 오류가 나면 실패입니다. Hit Error Meter를 게임 설정에서 켜고 크기·모양·표시·판정 위치를 확인합니다. Overlayer의 텍스트와 마스크 및 작업 상태의 호환성 경고도 확인합니다.
5. 준비·게임 렌더·미디어 합성 단계에서 각각 취소해 봅니다. 게임 속도·입력 오프셋·키뷰어 누적 횟수·설정이 복구되고 다시 렌더할 수 있어야 합니다. 가상의 재생이 실제 클리어 기록이나 개인 키 횟수를 저장하면 실패입니다.
6. 완료 화면의 **저장 위치 열기**로 선택한 폴더가 열리는지 확인합니다. 웹 다운로드 폴더에 복제본이 생기지 않아야 합니다. H.264, 10-bit H.265, ProRes 프로필 등 선택한 설정이 최종 합성 영상에도 유지되는지 확인합니다. 게임 오디오를 끄고 마이크만 포함하는 경우도 확인합니다.
7. 수정된 ImplDmNote를 켜고 Render의 ImplDmNote 옵션만 선택합니다. 자동으로 렌더 모드에 들어가고 실제로 키·마우스를 눌러도 영상에 섞이지 않아야 합니다. 앞·중간·끝의 짧은 입력과 홀드를 비교합니다. 완료·취소·앱 또는 IPC 종료 뒤 실제 입력이 복구되며 앱의 원래 프리셋·카운터·플러그인 저장값이 바뀌지 않아야 합니다.
8. 이동된 레벨, 훼손된 CSV, 권한 없는 저장 폴더 등에서 실제 원인과 다음 행동이 안내되는지 확인합니다. CSV 오류에는 해당 필드·행·파일이 표시되어야 합니다.
9. 중간 타일·체크포인트에서 시작한 기록을 렌더합니다. 시작 타일, 진입 전 대기, 음악 위치, 첫 판정과 카메라/ImplDmNote 입력 시점을 일반 리플레이와 비교합니다. 배속과 별도 카운트다운을 사용하는 레벨도 확인합니다. 중간 시작에서 클리어한 기록과 중간 시작에서 죽은 기록을 각각 확인합니다.
10. 실패 기록에서 **오디오·종료·게임 표시 → 클리어·사망 후 대기 시간**을 0초와 2초로 렌더합니다. 입력을 놓쳐 죽는 경우와 너무 이른 입력으로 죽는 경우 모두 행성이 줄어들고 폭발해야 합니다. 0초에도 폭발 프레임이 포함되며, 2초 영상은 그 뒤 약 2초 더 남아야 합니다. 사망 후 실제 키 입력으로 재시작하지 않아야 하며, 이 대기 중에도 취소할 수 있어야 합니다.
11. 자동 배치에서 게임 창을 최소화하거나 다른 macOS 공간에 둔 상태로 ImplDmNote 포함 렌더를 시작합니다. 창 정보를 읽지 못하면 웹에 대기 이유와 취소가 표시되어야 합니다. 게임 창을 복원하고 클릭하면 자동으로 재시도하며 위치·크기는 복원된 창을 기준으로 계산되어야 합니다. 대기 중 취소, 포커스 없이 30초 경과, 포커스가 왔지만 창 정보 조회가 계속 실패하는 경우의 오류를 확인합니다. 수동 배치와 오버레이 창 누락·캡처 실패·IPC 연결 끊김은 기존대로 처리되어야 합니다.

문제가 생기면 기록 ID, 모드·앱 버전, 작업 상태의 오류 코드와 상세 정보, `TUFReplay-Renderer` 게임 로그를 함께 남깁니다. 레벨이 녹화 뒤 바뀌었다면 녹화 당시 파일을 복구해야 합니다.
